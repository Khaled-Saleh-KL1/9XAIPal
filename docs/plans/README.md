# Plans

Active plans, findings, thoughts, future/urgent work, implementation plans.
Large plans carry a `## Segmentation` section so they can be cut into `../tasks/` handoffs.
Done -> move to `../archive/YYYY-MM-DD/` and add a row to `../archive/README.md`.

For the implemented v3 Arabic routing and recent releases, start with the
[changelog](../../CHANGELOG.md) and [current feature catalogue](../05-features/README.md).
A dated plan is an implementation record, not a current runtime contract. In
particular, the earlier Arabic printed-only/disabled rollout assumptions have
been superseded by the source behavior documented in
[Arabic routing](../05-features/16-arabic-document-routing.md).
